## Reproduktion

Python mit NumPy, SciPy, Pillow und pyGPlates 1.x installieren. Die folgenden Befehle laufen nur im Entwicklungsprojekt.

```sh
python scripts/g5/sources.py /tmp/georisiko-modelle
for modell in past ultima novo aurica amasia
do
  python scripts/g5/time.py /tmp/georisiko-modelle "$modell"
done
python scripts/g5/catalog.py
python scripts/g5/terrain.py
```

Die sechs hochaufgelösten Oberflächen (-surface.webp) sind bearbeitete Ausschnitte von **EOxCloudless 2024 by EOX IT Services GmbH, contains modified Copernicus Sentinel data 2024**. Sie werden unter **CC BY-NC-SA 4.0** weitergegeben. Bearbeitung: gedrehtes regionales Raster, bilineare Abtastung, Bildkompression und NASA-Bathymetrie über offenen Wasserflächen. Die unveränderten Archivdaten bleiben getrennt. Abfrage, räumliche Ausdehnung und Prüfsumme je Bild stehen in terrain/surface-sources.json. Die Normalenkarten beruhen auf der feinen Reliefabweichung vom geglätteten Höhenraster. [EOX](https://cloudless.eox.at/) · [Lizenz](https://creativecommons.org/licenses/by-nc-sa/4.0/)

Für die Zukunft werden die zehn Plattenkennungen der veröffentlichten Kontinentpolygone getrennt trianguliert. Die App dreht diese Körper mit den endlichen Rotationen aus den jeweiligen Szenarien. Zwischen jahresmillionengenauen Quaternionen wird auf der Einheitskugel interpoliert. Die historischen Zeitschnitte bleiben getrennte Rekonstruktionen. scripts/g5/future_mesh.py und scripts/g5/evidence.py erwarten als Argument den von sources.py erzeugten Ordner. scripts/g5/materials.py erzeugt die Satelliten- und Materialkarten.

## Strukturdaten der Referenzregionen

Die bei **Namen zeigen** zuschaltbaren Strukturlinien haben eigenständige Herkunft. Die Parkfield-Störung (UCERF3, UCF_32, rechtslateraler Versatz) stammt aus dem GEM Global Active Faults Dataset, Commit 56816508. Die Linie wird als bearbeiteter räumlicher Ausschnitt unter CC BY-SA 4.0 bereitgestellt. Die Lage des Japangrabens stammt aus USGS Slab2, trenches_usgs_2017_depths.csv, Commit f53d627e, Teilgebiet jap. Referenzquelle, Prüfsumme und Originalkoordinaten liegen in src/observatory/traces.json. Die eingezeichnete tiefere Bruchfläche ist eine getrennte Idealisierung. [GEM](https://github.com/GEMScienceTools/gem-global-active-faults/tree/56816508ad92fd6846dad1163b1c8c01376a2cd1) · [Lizenz](https://creativecommons.org/licenses/by-sa/4.0/) · [USGS](https://github.com/usgs/slab2/tree/f53d627ef36cc6a566c6ccd241f7d931fee8ef63)

Zusätzliche niedrigere Geländestufen bis zur vierfachen Breite verbinden den detaillierten Ausschnitt mit dem Horizont. Abfragen und Rastergrößen stehen in terrain/context-sources.json. Die Rauheitskarten schätzen die optische Wirkung aus Oberflächenhelligkeit und Wasserfarbe. Das Materialbild ist keine Rauheitsmessung. Für eine Neuerzeugung zunächst faults.py, danach terrain.py, materials.py, roughness.py und context.py ausführen. Die historische Netzmaske stammt aus den originalen deformierenden Netzen. Der unabhängige Vergleich von sechs Zeitschnitten mit den GPlates Web Services ist in g5-referenz.json dokumentiert.
