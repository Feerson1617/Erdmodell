GeoRisiko 3D lokal öffnen

Die Karten und das 3D-Modell werden über einen lokalen Webserver geladen. Entpacke das Unterrichts- oder Sichtprüfungs-ZIP vollständig.

Auf dem Mac öffnest du im entpackten Ordner START.command. Dafür wird Python 3 benötigt.

Im Terminal startest du das Modell im entpackten Ordner mit python3 start_lokal.py. Unter Windows funktioniert auch py -3 start_lokal.py.

Der Starter öffnet das Modell im Browser. Bei Bedarf kopiere die angezeigte Adresse mit 127.0.0.1 in den Browser. Lass das Terminal während der Nutzung geöffnet.

Das SCORM-ZIP lässt sich direkt in den Kurs im Lernmanagementsystem importieren.
